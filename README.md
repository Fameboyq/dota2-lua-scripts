## 🇺🇸 English Guide

### 🚀 Installation

1. **Clone the repository:**
   ```bash
   git clone https://github.com/Fameboyq/dota2-lua-scripts.git
   ```

2. **Copy to Umbrella Scripts Folder:**
   * Open your Umbrella cheat installation folder.
   * Navigate to the `scripts/` directory.
   * Copy the `dota2-lua-scripts` folder into `scripts/` (or copy individual modules into your custom scripts folder).

3. **In-Game Activation:**
   * Open the Umbrella menu in Dota 2 (`Insert` or default keybind).
   * Enable the modules under **Heroes** and **Utilities**.
   * Configure custom keybinds to your preference.

## 🇷🇺 Инструкция на русском

### 🚀 Установка

1. **Скачайте репозиторий:**
   ```bash
   git clone https://github.com/Fameboyq/dota2-lua-scripts.git
   ```

2. **Установка в чит:**
   * Откройте папку вашего чита Umbrella.
   * Перейдите в папку `scripts/`.
   * Закиньте скрипты в эту папку.

3. **Активация в игре:**
   * В матче откройте меню чита на `Insert`.
   * Во вкладках **Heroes** и **Utilities** появятся переключатели для Shadow Fiend, Invoker, Legion Commander и Auto-Items.
   * Назначьте удобные клавиши комбо.
